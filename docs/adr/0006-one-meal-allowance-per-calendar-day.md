# One meal allowance per user and calendar day across trips and employers

The daily meal entitlement is computed across all of a user's trips and employers, with no setting to allow duplicates; amounts already frozen in submitted claims are subtracted and only the remainder goes to the editable trip ending latest. Per-trip calculation would be simpler but could pay the same day twice. This is a conservative baseline and complex cross-employer allocation still needs validation before production. Rules C06 and C07 in CALCULATION_RULES.md define the mechanics.
