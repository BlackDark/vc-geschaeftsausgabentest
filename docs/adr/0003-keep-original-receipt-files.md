# Keep original receipt files indefinitely; previews and exports are derivatives

Confirmed receipts keep the exact uploaded bytes for good, and previews and export images are derived copies. Lossy compression or disposal of originals cannot be undone, so it stays off the critical path; the cost is more storage and that originals can carry EXIF/GPS data and need the same protection as financial records. A production retention and deletion policy is still open (see DECISIONS.md).
