# Go backend with Huma and a generated Hey API client

The backend is Go with Huma (code-first OpenAPI), and the React SPA uses a TypeScript client generated by Hey API from that OpenAPI document; SQLite with goose is the only database. Go keeps the container image (~60–80 MB) and memory small, and Huma removes a hand-written API spec. Swapping the backend language or the generator pipeline later would mean rewriting the API layer and client, so this is a lock-in choice.

## Considered options

- Bun + TanStack Start: one language end to end, but a larger image and runtime.
- Rust + axum: small and fast, but slower to iterate for a personal tool.
- Go + tygo: types shared without OpenAPI, but no generated validation, schemas or query hooks.
